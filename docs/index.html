Up and running in under a minute

BrandLint is a local Node.js server. No database to provision, no API keys to manage, no accounts to create.

View on GitHub →
# Clone and install
git clone github.com/priyasahay/BrandLint
cd brandlint && npm install
 
# Start the server
npm run dev
 
# Open in browser
http://localhost:3000
